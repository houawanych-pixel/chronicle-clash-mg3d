# Provenance
The character meshes, skeletons, animation clips and training geometry in this build are procedurally authored for this project. No character sprite sheets, proprietary game assets or Metal Gear source code are included. Meshes are blockout art, not finished character assets.

Synthesized sound cues are reused from Chronicle Clash MG Build 01. DejaVu Sans fonts are included under the license reproduced in DejaVu-fonts.txt.
