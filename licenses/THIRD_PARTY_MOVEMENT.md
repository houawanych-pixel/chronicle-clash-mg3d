# Movement references (MIT)

Chronicle Clash's traversal code (`scripts/citadel/Traverse.gd`) was written for
this project. Two MIT-licensed Godot projects were studied for approach; no source
files were copied into the game. Their notices are kept here as a courtesy and so
that any later reuse of their code stays compliant.

No Nintendo code, art, animation or assets are used. The glider model is built
from simple panels in Chronicle Clash colours.

## Climb 'n' Glide Character Controller
https://github.com/acegiak/g4-climb-n-glide-character-controller
Idea used: glide while airborne at a reduced fall speed; per-action stamina drain.
